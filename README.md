# Пушкинский музей — навигация (React)

Фронтенд мобильного приложения навигации по музейному городку ГМИИ. Сгенерирован 3 октября 2026 из последней версии прототипа — **v05** (`прототип/версии/v05_03-10_карта-городка-в-стиле-иллюстраций-…`): то же поведение, те же данные, тот же вид Material Design 3.

React 19, JavaScript, Vite 6, архитектура Feature-Sliced Design, состояние — zustand.

## Запуск

Нужен Node.js 18.17+ (лучше 20 или 22). Две команды:

```bash
npm install
```

```bash
npm start
```

`npm start` собирает приложение и запускает сервер на http://localhost:8787: он раздаёт приложение и строит маршруты «Свой в Пушкинском» через YandexGPT. Чтобы ИИ работал, скопируйте `.env.example` в `.env` и впишите ключ и каталог Yandex Cloud. Без ключа сервер отдаёт демо-маршрут и пишет об этом на экране.

Для разработки — два терминала: `npm run dev` (приложение с горячей перезагрузкой) и `npm run server` (API на порту 8787; Vite проксирует к нему `/api`). Без сервера зачёт показывает ошибку и предлагает демо без ИИ.

## Структура (FSD)

Слой может импортировать только нижележащие слои. Слайсы одного слоя друг друга не импортируют; где сущности нужна соседняя, это сделано через `@x` (например, `entities/hall/@x/route.js` — то, что зал отдаёт маршруту). Снаружи слайс открыт только через свой `index.js`.

```
src/
  app/        точка входа, рамка телефона, прокрутка экрана, объявления диктору, глобальные стили и токены
  pages/      map · routes · quests · search · visit — пять вкладок
  widgets/    map-header · floor-plan · campus-map · route-panel · location-panel · place-sheet · tab-bar · search-results ·
              quest-list · quest-start · quest-player · zachet-flow · moderator-panel
  features/   open-place · select-building · select-floor · toggle-crowd-layer · route-settings · mark-location ·
              build-route · route-progress · toggle-saved · toggle-seen · filter-tours-by-time · search-collection ·
              choose-quest-language · answer-quest-task · translate-quest-task · navigate-quest · reset-quests ·
              zachet-route · zachet-detail · zachet-voice · zachet-save · zachet-postcard
  entities/   building · hall · artwork · tour · crowd · visitor · route · quest · exhibit · zachet
  shared/     ui-кит M3 (Button, Chip, Switch, Segmented, List, Panel, MapSurface, Illustration…),
              lib (plural, normalize, safeStorage, asButton), config (иконки, вкладки), model (состояние интерфейса)
server/       Node.js без зависимостей: раздаёт приложение, /api/route (YandexGPT) и /api/health
data/         выгрузка каталога музея; scripts/ — её перенос в entities/exhibit
```

| Где | Что |
|---|---|
| `entities/*/model/*.js` | Справочники: здания, улицы, время пешком, залы, двери, переходы между этажами, произведения, готовые маршруты, загруженность. Новое — строкой |
| `entities/route/model/` | Граф переходов, кратчайший путь (Дейкстра), путь через остановки, «ближайшее первым», шаги для людей, пересчёт маршрута |
| `entities/visitor/model/store.js` | «Мой визит»: где я, сохранённое, увиденное, «без лестниц». Переживает перезагрузку (localStorage, ключ `pushkin-navigator-v1`) |
| `shared/model/uiStore.js` | Вкладка, здание и этаж на карте, открытый лист, слой толпы, запрос поиска, фильтр времени |
| `shared/config/icons.js` | Значки Material Symbols. Новый значок — сюда **и** в `icon_names` в `index.html`, по алфавиту |
| `app/styles/tokens.css` | Роли цвета M3 (светлая и тёмная схема), форма, подъём, шрифты. Своих hex в компонентах нет, кроме рамки телефона |

## Квесты для иностранных студентов

Вкладка «Квесты» (добавлена 3 октября, в прототипе v05 её нет). Два квеста по 7 заданий: «От Дега до Пикассо» (Галерея) и «Античность и слепки» (Главное здание). В каждом все пять типов заданий: найти (ответ числом), логика, внимательность (выбор из вариантов), творчество (подпись к картине, фото в позе статуи), общение (спросить смотрителя, обменяться подсказкой с другой командой — с готовой русской фразой).

- **До квеста** студент выбирает страну (она задаёт родной язык; для «Другой страны» язык выбирается отдельно) и язык прохождения: **по-русски** или **на родном**. Выбор языка прохождения — чипы на странице «Квесты» и на экране старта; это одна запомненная настройка, квест запускается кнопкой «Начать». Подписи — на двух языках сразу.
- **По-русски:** интерфейс и задания на русском; кнопка «Перевести · Translate» показывает под заданием, вариантами, подсказкой и объяснением перевод на родной язык.
- **На родном:** всё на родном языке, арабский — справа налево. Названия залов остаются русскими, как на табличках в музее; фразы для разговора — по-русски с переводом.
- У каждого задания: зал и «Как пройти» (строит маршрут на карте), подсказка, после ответа — короткий факт. Неверный ответ можно повторить или открыть верный. Счёт — сколько заданий с ответом решено с первой попытки. Прогресс переживает перезагрузку (ключ `pushkin-quests-v1`).
- **Квест для своей страны.** На странице «Квесты» студент выбирает страну: Египет, Китай, Испания, Латинская Америка, Франция, Бельгия, Великобритания или «Другая страна». Страна задаёт родной язык и добавляет к двум общим квестам свой: «По следам фараонов», «Символы удачи и долголетия», «Испания в Пушкинском», «Латинская Америка в Пушкинском», «Париж и французские мастера», «Фламандцы и Бельгия», «Британский след». **Каждый вопрос связывает экспонат со страной студента**: где он сделан, как попал в музей, что значит в этой стране (Саккара у Каира, Барселона Пикассо, «мексиканские» джунгли Руссо, ван Гог, проданный в Брюсселе, Пуссен из английского замка и т. д.). Тексты — на русском и языке страны. Что учтено для каждой страны — поле `culture`; общеизвестное, чего нет в каталоге, помечено в `note`. «Другая страна» — общие квесты и выбор языка перевода. Страны — `shared/config/countries.js`; новая страна — строка там и квест в `entities/quest/model/countryQuests.js`, только если экспонаты с ней действительно связаны.
- **Экспонаты — из каталога музея.** `data/pushkin-collection.json` (выгрузка, 97 экспонатов) переносится в `entities/exhibit` скриптом `python3 scripts/import_collection.py`. В задании видна карточка экспоната, как этикетка в зале. Годы в ответах сверяются с каталогом автоматически. Зал на схеме приложения подобран по номеру зала музея, для Галереи — по художнику; у 15 экспонатов (`hallSource: 'guess'`, среди них Руссо и Синьяк из квестов) зал угадан по периоду — проверить в музее. Экспонаты без здания (монеты, гравюры, графика) в квесты не взяты: в экспозиции их, судя по выгрузке, нет.
- **Итог квеста** — в развлекательной форме: конфетти и кубок, звание по доле ответов с первой попытки (от «Начинающего искателя приключений» до «Магистра музейных тайн») с шуточной фразой, четыре числа (с первой попытки, заданий, подсказок, залов), награды за каждый тип заданий и «Без подсказок», подписи студента к картинам цитатами и путь по заданиям с исходом каждого. На языке квеста; в режиме «по-русски» — с кнопкой перевода. Звания, награды и тексты — `entities/quest/model/summary.js`, расчёт — `entities/quest/lib/summary.js`.
- Новый квест или задание — запись в `entities/quest/model/quests.js`, новый язык — строка в `shared/config/languages.js` и блок в `entities/quest/model/strings.js`.

**Перед настоящим запуском:** переводы — черновик, их должны вычитать носители языков; задания нужно пройти в залах (музей перевешивает работы). Ответы — годы из справочника произведений и общеизвестные детали картин и скульптур; вопросов, ответ на которые не проверить (например, про конкретную витрину с монетами), в квестах нет.

## «Свой в Пушкинском» — зачёт у профессора Цветаева

Персональный маршрут-квест по Главному зданию по промпту `ПРОМПТ.md`. Он живёт на вкладке «Квесты» карточкой над остальными квестами и проходится отдельно: **логика остальных квестов (общих и по странам) не менялась**.

**Сюжет.** Музей создал профессор Цветаев как учебный, для студентов Московского университета. Студент получает музейную зачётку; каждая остановка — строка в ней, за пройденную ставится штамп «зачтено»; закрыл зачётку — собирает открытку домой.

**Экраны:** приветствие (сюжет, боль, три обещания, язык интерфейса: русский, английский, китайский) → параметры (страна, специальность, уровень русского, время 30/45/60/90 мин = 3/4/5/7 остановок, интересы, свободный текст до 300 знаков, язык рассказа — 16 языков, сложность) → сборка маршрута (четыре шага) → зачётка (название и вступление от ИИ, «Как ИИ понял твой запрос», кем собран маршрут, остановки со штампами, «Что ещё есть») → остановка (фото, зал, название, автор, дата, материал, размер; «Покажи смотрителю» — крупная русская фраза; «Почему это в твоём маршруте»; рассказ; «Для тебя»; шаг 1 «Найди деталь» с подводкой из культуры страны, таймером, тремя вариантами и подсказкой; шаг 2 «Голосовое домой» — тема и таймер на 20 секунд, запись в своём мессенджере; шаг 3 — штамп, русское слово с транскрипцией и переводом, «в этом же зале», «Вернусь сюда») → «Что ещё есть» (схема домов 12 и 14 на Волхонке; в Галерею не ведём) → открытка («Пушкинский за N минут», подписи остановок, фраза семье, «В следующий раз», «Скопировать открытку»).

**Игровые правила.** Первокурсник — 90 с, подсказка видна сразу, 10 очков; старшекурсник — 60 с, подсказка по кнопке, 15; аспирант — 45 с, без подсказок, 20. С первой попытки — полные очки, после ошибки — половина, до конца таймера — ещё +5; после таймера ответ всё равно засчитывается. Сверху закреплена полоса: сколько зачтено и сколько минут осталось. Награды: Первый зачёт, Зоркий глаз, Голос дома, Говорю по-русски, Есть план, Отличник, Свой в Пушкинском — новая всплывает сообщением. Прохождение хранится в `localStorage` (ключ `pushkin-zachet-v1`); жучок модератора сбрасывает и его.

**ИИ.** Сервер `server/` (Node.js без зависимостей) делает два вида запросов к YandexGPT (`jsonObject: true`): план маршрута (разбор запроса, ровно N экспонатов, порядок по зонам, причина каждого, название и вступление) и материалы каждой остановки — параллельно. Задание «найди деталь» начинается с подводки из культуры страны (`task.lead`); примеры из промпта переданы модели как образец. Свободный текст посетителя передаётся как данные, не как инструкция.

**Надёжность.** Сервер отбрасывает несуществующие id и повторы, оставляет не больше двух экспонатов из зала, ставит по зонам, проверяет задание (три разных варианта, верный — от 0 до 2). Нет плана — подбирает экспонаты по интересам; нет материалов остановки со второй попытки — простой текст из каталога и задание по этикетке. Нет ключа — готовый демо-маршрут (4 остановки, тексты на русском, английском и китайском, задания для Китая, Индии и Центральной Азии — примеры из промпта). На зачётке всегда видно, кем собран маршрут. Ошибки — понятным текстом с «Попробовать ещё раз».

**Данные.** В маршрут идут 30 экспонатов Главного здания с кодом зала. Таблица залов (код, название на трёх языках, название для смотрителя, зона обхода) — `src/entities/zachet/model/halls.js`; номера показаны только у зала 1 (Египет) и 15 (Итальянский дворик). Код: `entities/zachet`, `features/zachet-*`, `widgets/zachet-flow`, сервер — `server/`.

**Сверить в музее перед запуском:**
- порядок зон обхода в таблице залов — наше прочтение здания;
- что код 186 — зал 1, а 198 — Итальянский дворик (зал 15), и названия залов для смотрителей;
- что фото открываются с `https://arts-museum.ru` (пути из выгрузки);
- что экспонаты висят в указанных залах (музей перевешивает работы);
- демо-маршрут: рост статуэток (44 и 33 см), лотос в колье Раннаи, яблоко на круглом блюде у Рембрандта, старушка на санках у Аверкампа — проверить глазами;
- у слепков (Давид, «Златые врата») поле «материал» в выгрузке — материал оригинала; места оригинала в выгрузке нет;
- переводы текстов интерфейса на английский и китайский — вычитать носителям.

**Проверка без сети** (JavaScriptCore): каталог — 30 экспонатов, все залы в таблице, номера только у залов 1 и 15; профиль; чистка плана (чужие id, повторы, третий из зала, порядок); проверка задания; запасной подбор (N штук, ≤2 из зала, по зонам, по интересам); запасное задание (верный ответ — с этикетки); текст посетителя не попадает в инструкции; демо для пяти стран на трёх языках; факты демо-заданий подтверждены описаниями каталога; очки, награды, время; маршрут целиком — демо, исправная модель, сломанная модель, наполовину сломанная (167 проверок; намеренно сломанные «≤2 из зала» и ответ запасного задания ловятся).

## Панель модератора (жучок)

Кружок с жучком в правом нижнем углу (на телефоне — над панелью навигации) открывает панель модератора. Это демо-инструмент, как жучок в прототипах ЛК и модератора: в приложение для студентов он не входит. Esc или повторное нажатие закрывают панель.

- Панель показывает состояние квестов: страна, язык, сколько пройдено и в процессе.
- **«Сбросить квесты к началу»** возвращает всё, как у нового студента: без прогресса, без выбранной страны, родного языка и языка прохождения — и открывает список квестов. «Мой визит» и маршрут на карте не трогаются. Если сбрасывать нечего, кнопка неактивна и объясняет почему.
- Код — `widgets/moderator-panel`, сброс — `features/reset-quests`. Перед выпуском для студентов жучок нужно убрать из `app/App.jsx` или спрятать за флагом сборки.

## Что изменилось при переносе

- Имена файлов, папок, переменных, CSS-классов и идентификаторов данных — на английском (`гз-1` → `main-1`, `гал-рен` → `gallery-renoir`, `.узел` → `.node`). Тексты интерфейса — прежние, по-русски.
- Разметка строками (`innerHTML`) заменена компонентами; иллюстрации и фасады — JSX вместо склейки строк SVG.
- Поведение то же: модальный лист с возвратом фокуса, Esc и стягиванием вниз; `inert` за листом; объявления диктору; прокрутка к схеме после действий.
- Старые сохранения прототипа (ключ `пушкинский-навигация-v1`) не подхватываются: идентификаторы залов и работ другие.

## Проверка

Квесты: все тексты есть на шести языках, залы существуют, правильный вариант в пределах списка, ключи интерфейса совпадают во всех языках, числовые ответы сходятся со справочником произведений, проверка ответа принимает «1873 г.» и отвергает 1874 (93 проверки, удалённый перевод и неверный индекс ответа ловятся). Итог: звание на каждой границе, награды, счёт подсказок, цитаты, путь и все тексты на шести языках (197 проверок; сдвинутая граница звания и пропавший перевод ловятся). Квесты по странам: языки, залы, экспонаты в экспозиции, совпадение зала и года с каталогом, по одному квесту на страну, упоминание страны в каждом вопросе (1237 проверок; неверный год, пропавший перевод, вопрос без связи со страной и чужой язык квеста ловятся).

Логика маршрутов и поиска сверена с прототипом v05 в JavaScriptCore: кратчайший путь и шаги для каждой пары узлов при всех сочетаниях «без лестниц» / «в обход толпы», пути готовых маршрутов, порядок «ближайшее первым», 16 поисковых запросов — расхождений нет (16 287 сравнений). Порча одной двери в данных ловится этой сверкой.

В браузере проект ещё не запускался: на машине, где он сгенерирован, не было Node.js.

## Что в данных не настоящее

Как и в прототипе: схемы этажей условные (сверены только номера залов), загруженность — демо-данные, время пешком между зданиями — оценка. Подробно — `../README.md`.
